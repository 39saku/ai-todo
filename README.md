# AI Smart TODO & Calendar 🚀

AIによる入力補助とタスク依存関係管理を備えた、次世代TODO管理アプリ。

## 📌 プロジェクト概要
このアプリは「入力の手間を最小限に、管理の質を最大限に」をテーマにしています。
AIがメモ内容から「期限」「カテゴリー」「タスクの前後関係」を読み取り、自動で整理します。

### 🌟 主な機能
- **AIインテリジェント入力**: 自由な入力メモからタスク情報を自動抽出。
- **タスク依存関係管理**: 「Aが終わらないとBができない」という流れを可視化。
- **ハイブリッド・ビュー**: リスト形式とカレンダー形式の切り替え。
- **共有機能**: 複数人でプロジェクトの進捗を管理。

## 🛠 技術スタック (予定)
- **Frontend**: Next.js (TypeScript)
- **Styling**: Tailwind CSS, shadcn/ui
- **Backend/DB**: Supabase (PostgreSQL)
- **AI API**: OpenAI API (GPT-4o)
